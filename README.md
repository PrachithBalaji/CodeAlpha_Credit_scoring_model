# Credit Scoring Model Using Machine Learning

## Project Overview

This project predicts whether a customer is a Good Credit Risk or Bad Credit Risk using Machine Learning algorithms.

The system analyzes customer financial details and provides a creditworthiness prediction along with a loan approval recommendation.

## Features

* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Model Training
* Model Evaluation
* Credit Risk Prediction
* Model Saving using Joblib

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

* XGBoost
* Joblib

## Machine Learning Models

* Logistic Regression
* Decision Tree
* Random Forest
* XGBoost

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC Score
